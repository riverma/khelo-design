# Changelog

All notable changes to Khelo are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-16

### Added
- First release of Khelo, a design system for play.
- Two aesthetics: Khelo Mela (day) and Khelo Raat (night), following the OS
  until a choice is stored.
- Seven truck-art hues (genda, haldi, kesar, rani, firozi, tota, mor) with
  paper and kajal grounds for Mela, and lamplight and neel grounds for Raat.
- Rozha One, Yatra One and Baloo 2, self-hosted, Latin and Devanagari.
- Block lettering for big titles, sticker shadows, duotone poster bands
  with measured ink, and the kangura, bel, toran, string-light and
  rangoli-dot borders.
- A drawn icon set in `src/icons/` with `icons.css`. No emoji.
- Components: button, chip, link, icon, tile, card, panel, band, sticker, input,
  switch, notice, finite steps, ending.
- Docs site with overview, principles, foundations, components and
  for-agents pages, and a generated `SKILL.md` brief for agents.
- Gates: contrast, attention and offline.
